# Kif Récré /9

Concept seed: 9dc537fa. FORM world: playful physical sticker shop, with asymmetrical pasted artwork, chunky outlines, orange paper and compact retail shelves. The parent brief pins this world; the seed records this execution rather than selecting a different direction.

A sticker-shop storefront: saturated orange #fa5b21, paper #fff9ee and ink #1d211e, with cut-paper mint #c4ded0 and yellow #f8df5b. Oversized local Bebas Neue lettering provides the playful outline title; Outfit carries chunky retail headings; DM Sans provides readable controls. A loose, asymmetrical collage of actual Steam, Spotify and Netflix artwork sits across the hero, with captions and a circular pause sticker. Irregular flat paper geometry backs the collage. This is an expansive sticker wall, not a centered deck widget.

The catalog opens on all six products: one horizontal featured shelf with formula selection plus a compact product row. Four category controls and a global search expose Steam accounts, Steam gift cards, Xbox Game Pass, Spotify, Netflix and ExitLag. Related tiles select the featured formula area; selected variants add to the cart. Native dialogs contain the cart and two clearly simulated checkout paths. Manual CCP/BaridiMob remains separate from Chargily CIB/Edahabia.

A coordinated rocking collage has a visible pause-animation button. Reduced-motion suppresses both CSS movement and local Motion reveals; content defaults visible if imports fail. Mobile retains the three-artwork collage, stacks the feature shelf and uses two-column quick-selection tiles. Keyboard tabs, native dialogs, FAQ disclosures and mobile navigation are functional.

All assets and fonts are local; all prices and variants illustrative. Kif is a provisional name. No gradients, fabricated claims, live orders or payment collection. This finished HTML/CSS/JS alternative awaits a design choice before any Svelte work.
