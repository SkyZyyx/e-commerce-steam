# Kif — ten storefront design studies

Run `npm install` then `npm run dev`. Open http://localhost:5173 for the comparison page or `/1/`, `/2/`, `/3/` directly. `npm run build` builds all eleven entry pages; `npm run preview` serves the result.

- **1 / Boutique** — cream, orange, tactile Three.js product display.
- **2 / Club** — cobalt poster typography, tilted merchandise, acid yellow payment section.
- **3 / Première** — dark cinema wall, editorial serif, featured-game switching.

Current implementation is HTML, CSS and JavaScript, using locally bundled Motion (the vanilla JavaScript API from the Framer Motion ecosystem). Design 1 also uses Three.js. Svelte, Tailwind and DaisyUI implementation waits for design approval.

Each concept includes all requested product categories, interactive selection, a shopping cart and simulated checkout. CCP / BaridiMob are presented as manual transfer options; CIB / Edahabia are presented through Chargily. There is no live payment or order integration. Prices, variants and Kif branding are demonstration assumptions, not final commercial information. No payment credentials are requested.

Assets are local; see assets/sources.json and RESEARCH.md for source attribution and research boundaries. Third-party names and artwork remain their respective owners' property.

- **4 / Pop** — mint/pink interactive product deck.
- **5 / Sélection** — white/oxblood retail catalog and vertical navigation.

- **6 / Escale** — yellow/blue ticket-counter store.
- **7 / Studio** — chocolate/peach record-store concept.

- **8 / Terrain** — forest green sports editorial shop.
- **9 / Récré** — orange cut-paper sticker shop.
- **10 / Objet** — lilac and white product gallery with sculptural display.
